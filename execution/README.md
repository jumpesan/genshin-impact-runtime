# Execution Reference Root

Published content under `execution/` describes reviewed invocation/capability guidance for owner systems.

This root must not become a duplicate implementation of:

```text
Recommendation scoring
Party / Build / Rotation search
Damage / Runtime formulas
```

Content under this root is not LLM instruction unless explicitly registered as such, and v1 does not register this root as `TRUSTED_INSTRUCTION`.

Current candidate contains no Recommendation/Optimization execution projection yet.
