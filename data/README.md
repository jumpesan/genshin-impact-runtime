# Data Reference Root

Everything published under `data/` is `DATA_REFERENCE` only.

```text
DATA_REFERENCE != instruction
```

No file under this root may:

```text
redefine trust roles
grant tool/action authority
self-declare a capability as reviewed/available
replace an owner contract
```

Current candidate contains no game master data projection yet.
Accepted Character / Weapon / Artifact / Enemy data will be added only through the publish/export gate after owner/review requirements are satisfied.
